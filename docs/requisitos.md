Requisitos do Sistema – Lista de Tarefas 

1. Requisitos Funcionais 

RF01 – Adicionar tarefa: 
O sistema deve permitir que o usuário insira uma nova tarefa por meio do campo de texto e adicione-a à lista. 

RF02 – Validar tarefa: 
O sistema deve impedir que uma tarefa vazia seja adicionada. 

RF03 – Exibir tarefas: 
O sistema deve apresentar na tela todas as tarefas cadastradas pelo usuário. 

RF04 – Concluir tarefa: 
O sistema deve permitir que o usuário marque uma tarefa como concluída. 

RF05 – Identificar tarefa concluída: 
O sistema deve apresentar visualmente as tarefas concluídas, utilizando um efeito de texto riscado e alteração na cor do texto. 

RF06 – Excluir tarefa: 
O sistema deve permitir que o usuário exclua uma tarefa da lista. 

RF07 – Interação com as tarefas: 
O sistema deve permitir que o usuário interaja diretamente com as tarefas apresentadas na lista. 

2. Requisitos Não Funcionais 

RNF01 – Usabilidade: 
A aplicação deve possuir uma interface simples, intuitiva e de fácil utilização. 

RNF02 – Responsividade: 
A aplicação deve adaptar sua interface a diferentes tamanhos de tela, permitindo sua utilização em computadores, tablets e dispositivos móveis. 

RNF03 – Desempenho: 
As operações de adicionar, concluir e excluir tarefas devem ocorrer de forma rápida, sem atrasos perceptíveis ao usuário. 

RNF04 – Compatibilidade: 
O sistema deve funcionar em navegadores modernos compatíveis com HTML5, CSS3 e JavaScript. 

RNF05 – Interface: 
A aplicação deve apresentar uma organização visual clara, utilizando elementos como campos de entrada, botões e lista de tarefas. 

RNF06 – Manutenibilidade: 

O código deve ser organizado de forma que HTML, CSS e JavaScript permaneçam separados, facilitando futuras alterações e melhorias no sistema.
